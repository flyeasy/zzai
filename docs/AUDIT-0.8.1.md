# 0.8.1 验收审计：文档 vs 实现 vs 体验

> 目的：回答三个问题——**需求与设计有没有劣化偏差**、**有没有过度设计把体验改坏**、**这个版本能不能验收**。
> 方法：两路只读审计（mac：文档逐条对代码；Windows：`docs/win-parity.md` 逐条对代码 + VM 实测），加本会话的端到端证据。审计在 2026-11-21 由两个独立 subagent 并行做，结论由本人复核。
> 结论速览：**mac 可验收（版本 0.8.1、唯一安装）**；**Windows 可验收（有 4 条真机项必须你亲手过）**；偏差分三类，见下表，没有隐瞒的「文档说做了、其实没做」。

## 1. 先说结论

| 平台 | 版本 | 安装形态 | 验收判断 |
| --- | --- | --- | --- |
| macOS | 0.8.1（`Info.plist` 与 About 一致） | `/Applications/Eryu.app` 唯一一份，`build/`/`dist/` 副本已删、LaunchServices 只注册一份 | **可验收**：`--version` → `Eryu 0.8.1`，`--diagnose` 正常，`smoke.sh` 全绿（含 7 项极端状态矩阵、10 项局域网接口） |
| Windows | 0.8.1（`Eryu --version` → `Eryu 0.8.1`） | `%LOCALAPPDATA%\Programs\Eryu` 每用户安装，zip 内含 226MB 语音模型 | **可验收（附条件）**：自动化覆盖到「装完即能说话→出字→上屏」，剩 4 条必须真人做（见 §5） |

## 2. 偏差分类与处置

分三类，全部登记过，不靠记忆：
- **A 已修（本轮改代码）**：真的会让用户踩坑的。
- **B 文档口径修正（实现为准）**：实现是对的、文档写错/写旧了，改文档。
- **C 明确没做（留到下一版）**：设计与实现都没问题，但这一版没做，写明影响。

### A. 本轮修掉的（都有 VM/真机证据）

| 问题 | 根因 | 处置 |
| --- | --- | --- |
| 按热键后「什么都没发生」（录音没起来） | `overlay.error()` 从不 `ShowWindow`；随后 `idle` 事件把错误内容冲掉；80 字文案被尾部截断 | 错误浮层 3.2s 常驻（`ERR_UNTIL`）、按长度预设宽度、错误留头部（I-157）；浮层只说一句能照着做的话，全文进托盘。mac `matrix.sh` 7 项不变 |
| 桌面/任务栏焦点时「假装上屏成功」 | 逐字打字用 `WM_CHAR`，任务栏窗口照收、回读也读得到 | 前台是 `Shell_TrayWnd`/`Progman`/`FolderView` 等直接 `undelivered` + 提示（I-148） |
| 上屏后历史长期「待复制」、每次启动弹「上次没上屏」 | 提交等待 2s，Windows 上屏（UIA + 粘贴 + 回读）常超时；迟到的 ok 被 `NoPending` 丢弃 | 等待 6s + 迟到 ok 也认（I-142） |
| 升级后仍用旧 `eryu_core.dll` | 内置 dll 指纹是「长度+首末字节」，core 改几百行不变 | 改 FNV-1a 内容哈希（I-141） |
| 一次 panic 后界面连锁点不动 | 183 处 `Mutex::lock().unwrap()`，锁中毒后每次取锁都 panic | 统一 `crate::lock()`（沿用最后值） |
| 开关点了不落盘（记录历史/只认我的声音） | 先 `match id` 读状态、后 `flip_toggle`，写回的是旧值 | 先翻转再分支（I-135），逐项复验全部自绘开关 |
| 热词文件格式坏 → 规则全丢 | 整份 TOML 解析失败就留空，界面上再保存会写空模板 | 逐行兜底 + 页面橙色提示「只载入 N 条」（I-163） |
| 热键写错（如 `CTRL+`）静默退回 Alt | 解析把 `CTRL+` 当单键；失败只 `eprintln!` | 保存前校验并说明格式；启动时托盘提示（I-162） |
| 探针 / 试说页在没模型时白等 | 引导第 3 步（Windows 第 5 步）不检查引擎是否就绪 | 模型未就绪停在模型页，「下一步」灰显并说明（I-144） |
| 装完不能用（只有测试信号） | 安装包不含模型，引擎页平铺 6 个模型 | 模型三档：SenseVoice 随包、VAD/降噪内置、其余用到再下（D-113） |
| 诊断页是一屏 TOML，看不出问题 | 页面只把配置贴出来 | 第一屏改只读状态 + 四个动作，TOML 降到「高级」（I-147） |
| 出问题没法远程定位 | 只有本地日志 | 诊断包一键导出/上传（R-127 / D-114 / I-164），见 §4 |
| 发版包里带测试口 | `--set-config` 等能改用户数据；`--assume-consent` 顺带把全局对话框降级 | 统一收进 `--dev`；同意跳过只作用于润色弹窗（I-165） |
| mac 装出来显示 0.7.0 | `packaging/Info.plist` 没跟上 | 对齐 0.8.1；`doccheck.sh` 兼容「未发布」版本头 |

## 3. 过度设计审计（用户 ⑤）

判断标准：**这一屏/这个按钮是不是「用户要用」，还是「我方便自己」**。按此清理了设置里最密的四屏：

| 页 | 清理前 | 清理后 | 依据 |
| --- | --- | --- | --- |
| 通用 | 「保存」+「保存覆盖」两个按钮 + 左下角「配置：%APPDATA%\Eryu」噪音 | 一个「保存」；配置路径只在诊断页出现 | I-151 |
| 历史 | 5 个按钮（刷新/复制/删除/清空/重试失败） | 一行四个：复制/删除/清空/重试失败（N）；说完一句列表自动刷新 | I-152 |
| 润色 | 6 个按钮（保存润色设置/测试连接/检测模型/用选中的档/保存槽/保存指令）+ 两处重复提示 | 4 个（保存/测试连接/用选中的档/保存指令），槽位并入「用选中的档」 | I-153 |
| 引擎 | 两行各自一个保存 + 常驻灰字说明 | 一个「保存」；说明收进 ⓘ；只列两个识别引擎 | I-154 / D-113 |
| 全局 | 解释性长句写在页面里 | 一句短文案 + ⓘ 悬停提示 | 用户 m05811（已写入长期偏好） |

仍然保留的「多」：声音页四个开关、局域网页参数——它们各有真实用途（降噪/标点/锁定音源/暂停媒体），不是测试口。

## 4. Windows 诊断能力（用户要求的「错误码 + 收集日志 + 上传」）

- **错误码**：所有面向用户的失败都带 `code`（`docs/ERRORS.md` 全表），并且**落盘**到 `%APPDATA%\Eryu\eryu-errors.log`（最近 20 条）——问题发生在上一次运行也能带进下一次诊断包。
- **一键诊断包**：设置 → 诊断「导出诊断包 / 上传诊断包」；CLI `--diag-bundle` / `--diag-upload`。内容七段：版本、系统（含 DPI/屏幕）、脱敏配置、核心自检、最近 20 条错误、历史条数分布、日志尾 200 行。
- **不含**：转写正文、历史文字、热词内容、API Key/Token（一律 `***`）。
- **上传**：`POST` 到 `[diag] upload_url`（默认 `https://officeace.harmonyos.fun/eryu-diag/upload`，和模型镜像同一台）。**注意：这个端点服务器上还没部署**，现在会明确回「服务端还没有开放诊断上传（404）：诊断包已存本地」——契约写在 `docs/WINDOWS.md`，你那边加个路由就能接。
- **实测**：VM 上导出 8.6KB、mock 收到 8613 字节（UA `Eryu/0.8.1`）；制造真实 `mic_unavailable` 后包内 `errors` 正确，`DIAGCODES 1`。

## 5. 你还需要亲手做的（自动化到不了的地方）

设备上没有真人麦克风、没有真键盘（注入键被低级钩子按 I-113 规则跳过），以下必须真机：

1. **真实麦克风说一句** → 出字上屏（VM 用的是 WAV 回放）；
2. **真实按键**按住/松开热键（VM 是 `--hotkey-sim`）；
3. **观感**：设置/胶囊/托盘在你的缩放比例（125%/150%/200%）下有没有重影——这是你 ④ 提的问题，VM 屏只有 1470×770，>110% 全部被同一档夹住，量不出来；
4. **双开**：第一份在跑时再点图标 → 应提示「已经在运行」并把设置窗叫出来（VM 已验，真机可复核）。

清单在 `docs/win-manual-test.md`（32 条，每条「怎么做/应该看到/怎么反馈」）；只看你这 4 条的话，A/B/D 组各抽一条即可。
