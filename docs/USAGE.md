# 怎么用 Eryu

一句话：**按住右 Option 说话，松手文字就进当前输入框**。识别全在本机。

## 日常三条

1. 按住 → 浮层出现「在听…」+ 电平条，边说边出字。
2. 说完松手 → 「识别中…」→ 「已上屏」。
3. 说错了：按住期间按 **Esc** 取消；已经上屏的用 ⌘Z（系统撤销）。

## 什么时候用哪个开关

> 同样的建议也贴在「设置 → 音频」页顶部（「什么场景开什么」），两处改一处要同步另一处。

| 场景 | 建议 |
|---|---|
| 办公室/家里，正常环境 | 默认就行（降噪开、补标点开） |
| 旁边有人说话/电视在响 | **关掉降噪**（竞争人声会让它更差，D-069）；或用电容麦离嘴 10cm |
| 外放音乐/视频时想说话 | 戴耳机；或设置 → 音频开「录音时暂停播放」 |
| 只想录自己的声音（多人会议） | 开「只识别我的声音」（先录 8 秒声纹）；插话多时再开「音源锁定」 |
| 旁边人声一直插话、你也想记 | 关音源锁定（它按段丢，宁可全留） |
| 输密码框 | 自动拒绝逐字上屏；粘贴模式也建议切走 |
| 英文/多语内容 | 设置 → 引擎切 Qwen3（更准但慢 3 倍、内存 2GB） |
| 写正式文案 | 设置 → 润色开「轻度」，或按档位快捷键（默认 ⌃⌥1/2/3） |
| 不想留痕迹 | 开隐私模式（不写历史、不落盘、浮层不显示文本） |

## 让别的设备也用这台机器的模型（局域网听写接口）

默认关闭；设置 → 音频 → 「局域网听写接口（实验）」打开，改完**重启 Eryu** 生效。

```bash
# 探活
curl -s -H "x-eryu-token: 你的token" http://127.0.0.1:8765/health
# 发一段 16k 单声道 WAV 要文字
curl -s -H "x-eryu-token: 你的token" --data-binary @speech.wav http://127.0.0.1:8765/transcribe
```

它只做「音频→文字」：不上屏、不写历史、不动剪贴板。默认只监听本机；要让手机访问得打开「允许局域网」，并且**一定设 token**。

## 三种"没反应"怎么办

**按了键没反应**
- 菜单栏图标有没有变化？没有 → 热键没接住：设置 → 通用 看有没有红字冲突提示；权限页看「输入监控/辅助功能」。
- 刚授权完 → 菜单「退出并重新打开」⌘⇧R。

**浮层出来了但没字**
- 看浮层右侧秒数有没有在涨：不涨 = 麦克风没录到（查设备/静音）。
- 涨了但一直是「在听…」→ 静音段太长，VAD 还没封口；正常说完整句会出字。

**松手后提示「声音太小了」**
- 峰值 <2% 一律不上屏（防幻觉，D-072）。靠近麦克风，或系统「声音 → 输入」把输入音量拉高。

**松手后提示「太短了」**
- 默认最短 400ms。双击热键可以取回上一次结果（不用重说）。

**文字没进输入框**
- 提示「上屏结果未知」→ 文字已保存，⌘C 从菜单复制。
- 目标应用是提权窗口/特殊控件 → 切「逐字打字」模式，或手动粘贴。

## 菜单栏常用

- ⌘C 复制上次结果（剪贴板）
- ⌘R 重试上次失败的识别
- ⌘. 取消当前录音
- ⌘E 选区改写（选中文字后按，5 条指令）
- ⌘, 设置　⌘H 统计与历史　⌘⇧R 退出并重新打开

