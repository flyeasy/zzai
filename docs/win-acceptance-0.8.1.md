# Windows 0.8.1 验收矩阵（自动化证据 + 真机待确认）

用途：一页看清「哪些已经用自动化在 VM 里验过、哪些只能真机确认」。真机步骤的详细描述在
`docs/win-manual-test.md`（32 条），本文只给每项一句话结论和证据出处。

产物：`dist-win/Eryu-0.8.1-win64.zip`（169MB，含 226MB 语音模型）。
VM 装机目录：`%LOCALAPPDATA%\Programs\Eryu`，最后一次部署的 exe 哈希前 16 位随提交记录。

## 六、自动化验不到、只能真机看的

1. **真实麦克风**的音质/延迟/换设备/系统默认设备切换。
2. **真实按键**的热键与选区改写（`Ctrl+Alt+E`）：VM 里注入键会被低级钩子按 I-113 跳过。
3. **输入法拼写中**按热键的行为（IME 合成串）。
4. **观感**：字号/清晰度/重影（用户 ④ 尚未给出具体窗口与缩放比例）。
5. **多显示器 / 高 DPI 真机**：VM 屏幕只有 1470×770，`fit_scale` 会把任何大于约 110% 的缩放请求夹住（125/150/200 都渲染成 994×698），所以 125%/200% 的观感只能真机看。110% 这一档已验：通用/音频/历史三页无裁切重叠。
6. **explorer 重启后托盘图标**（代码有 `TaskbarCreated` + 5s 定时复检，VM 里没稳定复现手段）。
