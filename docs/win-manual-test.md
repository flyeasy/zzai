# Windows 真机手测清单

> 目的：把「自动化测不到、只有真人和真设备能测」的部分收敛成一张表。
> 每条给「怎么做 / 应该看到什么 / 不对时告诉我什么」。30 条左右，10 分钟能走完。
> 版本：0.8.1（`Eryu-0.8.1-win64.zip`）

## A. 安装与启动

| # | 怎么做 | 应该看到 |
|---|---|---|
| A1 | 解压后双击 `install-win.bat` | 装到 `%LOCALAPPDATA%\Programs\Eryu`，开始菜单出现 Eryu，桌面出现快捷方式 |
| A2 | 启动 | 托盘出现图标；首次启动进引导，6 步（模型 → 麦克风 → 热键 → 上屏方式 → 试说 → 润色） |
| A3 | 引导第 5 步「试说一句」按住热键说一句 | 胶囊出现在屏幕底部并实时出字；识别对上才能点下一步 |
| A4 | 关掉引导再启动一次 | 不再弹引导（除非引导没走完） |
| A5 | 卸载（`uninstall-win.bat`） | 程序与快捷方式消失，配置/历史/模型还在（加 `-PurgeData` 才全清） |

## B. 说话上屏（核心）

| # | 怎么做 | 应该看到 |
|---|---|---|
| B1 | 记事本里按住右 Alt 说一句中文，松开 | 1–2 秒内文字落在光标处；胶囊显示识别中 → 已上屏 |
| B2 | 换一个 App（浏览器地址栏、微信输入框）再说 | 文字落在那里的光标处，不是落在上次的窗口 |
| B3 | 快速点一下右 Alt 再松手 | 不产生文字、不进历史（不足最短录音 400ms 直接丢弃）；不会误上屏 |
| B4 | 说话中间标点/数字/英文混说 | 中文标点正确，数字不出成汉字 |
| B5 | 录音时按 Esc | 取消，不上屏；媒体播放恢复 |
| B6 | 对着静音说（不放声音按热键） | 不上屏空文本，胶囊提示没有听清 |

## C. 观感（之前你提过的两点）

| # | 怎么做 | 应该看到 |
|---|---|---|
| C1 | 说话时看胶囊 | 润色徽标是**铅笔图标**（不是「日」字）；正文清楚；整体比 mac 略小或相当 |
| C2 | 浅色壁纸 / 深色壁纸各看一次 | 提示行文字都能看清（浅壁纸上不是白字） |
| C3 | 设置窗顶栏 | 右上角 ✕ 可点（不用拖到边缘），拖顶栏能移动窗口 |

## D. 设置页（键盘 + 鼠标）

| # | 怎么做 | 应该看到 |
|---|---|---|
| D1 | 打开设置，Tab 走一圈 | 焦点在按钮/开关/输入框/列表之间循环，有描边 |
| D2 | 焦点在开关上按空格 | 开关翻转；**关掉设置重开，状态还在** |
| D3 | `Ctrl+Tab` / `Ctrl+Shift+Tab` | 左侧页面上下切换；`Ctrl+1..9` 直达第 N 页 |
| D4 | 音频页点「测试麦克风」 | 电平条随说话跳动；切到别的页后电平条停（麦克风不再占用） |
| D5 | 历史页：选中一行 → 复制 → 删一行 | 剪贴板是那行文字；删除只少一条；**设置停在历史页时说一句，列表自己多一行（不用点刷新）** |
| D6 | 历史页「清空」 | 先弹确认框，点「否」不删 |
| D6b | 润色页：填 key → 保存 → 测试连接 → 选中一档 → 档位快捷键填 `CTRL+ALT+5` → 点「用选中的档」 | 连接测试有结果；重启后这一档仍是选中态、快捷键仍是 `CTRL+ALT+5` |
| D7 | 引擎页：下载附加模型（降噪/标点） | 有进度；完成后本句起生效 |
| D8 | 润色页：只开「启用润色」直接保存 | 档位自动变成「轻度」，说话后文字被润色 |
| D9 | 润色页：填地址/模型/Key → 测试连接 | 显示测试结果（成功或具体错误），不卡窗口 |
| D10 | 热词页：加一个词 → 说这句话 | 识别结果里该词按你写的形态出现 |
| D11 | 声纹页：录一段自己的声音 → 启用「只认我的声音」 | 自己说话照常上屏；别人说话被跳过 |
| D12 | 局域网页：开「允许其它设备访问」但不填令牌 | 拒绝启动并说明原因（安全设计） |
| D13 | 诊断页：看日志/打开数据目录 | 能打开 `%APPDATA%\Eryu`，日志有内容 |
| D14 | 任意页按 Esc、Alt+F4 | 设置窗隐藏（进程仍在托盘），再点托盘能恢复上次那页 |

## E. 托盘与自启

| # | 怎么做 | 应该看到 |
|---|---|---|
| E1 | 右键托盘图标 | 设置 / 历史 / 显示主窗 / 暂停 / 退出 等菜单项齐全，点「退出」进程真退 |
| E2 | 退出后按热键 | 不响应（真的退干净了，钩子已卸） |
| E3 | 资源管理器重启（任务管理器里重启 explorer.exe） | 托盘图标几秒内自己回来 |
| E4 | 设置里开「开机自动启动」→ 重启电脑 | 登录后自动起在托盘；关掉后不再自启 |
| E5 | 迷你主窗（小圆钮）拖到别处，点一下 | 开始录音，再点停止；重启后回到工作区右上角（和 mac 一样只记开关、不记位置） |

## F. 边界（不用全做，遇到问题再说）

| # | 怎么做 | 应该看到 |
|---|---|---|
| F1 | 拔掉耳机/麦克风说话 | 保住已录内容并提示，不崩 |
| F2 | 手动删掉模型目录再启动 | 提示下载模型，不是白屏或崩溃 |
| F3 | 同一台机器连开两次 Eryu | 只有一个实例，第二次把已有窗口叫出来 |
| F4 | 中文输入法正在拼写时按热键 | 不会把拼音一起吞进去，也不会卡住输入法 |
| F5 | 在记事本/浏览器里选中一段话，按 `Ctrl+Alt+E`，选「润色」回车 | 面板弹出（↑↓ 选、1-5 直达、Esc 收起）；执行后**原处被替换**，剪贴板里你原来的内容还在 |
| F6 | 焦点停在桌面或任务栏上再按热键说话 | 提示「焦点在桌面或任务栏上：先把光标放进要写字的输入框，再说一次」，不假装成功 |
| F7 | 打开设置 → 热词，在框里写一行 `今天天气 -> 今天天气真好`，点「保存热词」，再说一遍那句 | 「共 1 条」；上屏的句子把「今天天气」换成了「今天天气真好」（替换效果已用 `--decode-wav` 验过，这里看热键这条路是否一致） |
