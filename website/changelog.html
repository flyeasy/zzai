最新 v0.8.2·2026-11-22

v0.8.2

2026-11-22

一次以「装好就能用」为目标的更新，Windows 端改动最多。

安装与首次运行

  • Windows 解压后直接双击 Eryu.exe 就能说话：启动时自动把同目录 models\ 里缺的模型搬进 %APPDATA%\Eryu\models，不必先跑安装脚本，也不会一上来就要求下载 233MB。
  • macOS 安装包的版本号与「关于」显示对齐到 0.8.2。

设置页

  • 润色「附加要求」改用原生文本框，输入法与 ⌘V 不再失灵；字段左对齐、标签在上，说明收进 ⓘ。
  • 热词输入框每敲一个字就丢焦点的问题修好了。
  • 自己窗口里的 ⌘V / ⌘C / ⌘A 恢复可用。

听写与上屏

  • 说话时弹出别的窗口，结果不再贴进新窗口：按下热键就记住当时的应用，松手先切回去再上屏；切不回去只提示，文字留在剪贴板。
  • 长听写松手不再丢最后一句；超过 120 秒时改为保留开头那段。
  • 润色不再给出半句话：按输入长度带 max_tokens，服务端截断时这一句用原文，并在胶囊里说明。

界面

  • 菜单只留两行纯文本，去掉看不懂的图标与提示；排障入口收进 --dev。
  • 录音时胶囊文字变宽，整段中心不再逐格右移。

v0.8.1

2026-11-22 · 首个公开版本

字在第一次公开发布。macOS 与 Windows 两端功能对齐，免费、开源、无账号。

听写

  • 双引擎：SenseVoice 默认，Qwen3 短句精度档；设置里点下载、点切换。
  • 准流式浮层每 900ms 刷新预览，松手才上屏。
  • 长听写最长 120 秒，内部按 30 秒切段自动接续；修掉了松手时最后一句可能丢失的问题。
  • 说话中途弹了别的窗口，结果不会再贴错地方：按热键时记住当时的应用，上屏前先切回去；切不回去就只提示、把文字留在剪贴板。
  • 浮层录音时文字变宽不再整体向右漂移，中心保持稳定。

上屏

  • 粘贴与逐字打字两种方式，可按 App 覆盖。
  • 逐字打字不再往桌面或任务栏里打；目标吞字时如实报「没看到这段文字」。
  • 提权窗口、密码框无法注入，会明确提示而不是假装成功。

热词与改写

  • 热词只填「想听到的词」，听错的写法由程序从你的编辑里学。
  • 修复热词输入框每敲一个字就丢焦点的问题。
  • 选区改写 ⌘E：润色、正式、精炼、英文、总结五种，结果就地替换；粘回目标窗口在打开面板前就记下，不再粘到自己身上。

润色

  • 默认关闭；开启时明确提示文字会离开本机。
  • 润色不再返回「半句话」：服务端因长度截断时这一句用原文，并在浮层说明。
  • 默认档位固定为「轻度」，不会再出现开关亮着、文字却没变化。

隐私与诊断

  • 隐私模式：不写历史、失败音频不落盘、浮层不显示文本。
  • 诊断包一键导出 / 上传：脱敏，不含识别正文；失败保留本地文件并给出原因。
  • Windows 错误码落盘到 eryu-errors.log，最近 20 条随诊断包带走。

局域网听写（实验）

  • 默认关闭，只监听 127.0.0.1:8765；允许局域网必须设 token。
  • 令牌可一键生成，页面直接给出连接地址与可复制的 curl 示例。
  • 只做音频转文字：不上屏、不写历史、不动剪贴板。

界面与安装

  • 设置页信息层级重排：说明性文字收进 ⓘ，输入框标签在上、左对齐。
  • 菜单只留用户会点的两项，排障入口收进 --dev。
  • macOS 安装包版本号对齐 0.8.1；Windows 第二个实例不再弹误导框，直接把已有窗口叫出来。
  • 引擎页默认走内置镜像，不再要求填下载地址。

已知限制

  • macOS 仅 Apple Silicon（arm64）、13+；Windows 10/11 x64。
  • 两端都没有代码签名与公证，首次打开需要手动放行。
  • Qwen3 只适合 ≤30 秒的短句；竞争人声场景下降噪可能让 CER 变差。
  • 不做回声消除、不做繁简转换；没有自动更新、唤醒词或云同步。
