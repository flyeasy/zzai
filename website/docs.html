使用说明

从第一次按下热键，到热词、改写、局域网接口。按顺序读，或者直接跳到你要找的那一节。

适用 v0.8.1·macOS 13+ Apple Silicon·Windows 10/11 x64

五分钟上手

如果你已经装好并授权，只需要记住三件事：

  1. 按住右 Option（Windows 为右 Alt），浮层出现「在听…」和电平条。
  2. 说话，准流式文字每 900ms 刷新一次，但此时还没上屏。
  3. 松开，文字进入当前输入框；按 Esc 可以取消。

说错了但已经上屏：用系统的 ⌘Z / Ctrl+Z 撤销。双击热键可以取回上一次听写结果，不用重说。

第一次使用建议先打开「设置 → 音频 → 测试 3 秒」，确认电平条会动，再去任何输入框里试。

安装与权限

安装包与校验值在下载页。两个平台都没有代码签名，首次打开会被系统拦一次，这是预期行为。

macOS 的三项权限

权限位置不给会怎样
麦克风系统设置 → 隐私与安全性 → 麦克风收不到声音
辅助功能系统设置 → 隐私与安全性 → 辅助功能没法粘贴上屏，单键热键不响应
输入监控系统设置 → 隐私与安全性 → 输入监控键盘监听或合成 ⌘V 可能失败
权限是按 app 文件路径记的。给「应用程序」里的副本授过权，再启动项目目录里的另一份副本，系统仍然认为没授权。只保留一个可运行副本，并先移动、再授权。

从终端直接运行二进制会继承终端的授权，权限读数可能是假阳性。判断权限是否真的生效，请以双击启动的副本为准，或看菜单栏「权限状态…」。

Windows

解压后双击 install-win.bat 建快捷方式；首次启动会走五步引导。设置页支持 Tab / Shift+Tab 移动焦点、Ctrl+Tab 翻页、Esc 关闭。

浮层与状态

浮层不抢焦点，只显示在屏幕底部。它的状态很直接：

  • 在听…：正在收音，右侧秒数在涨；电平条随音量跳动。
  • 识别中…：你已松手，本机正在收尾。
  • 已上屏：文字已注入当前输入框。
  • 太短了 / 声音太小了：本次丢弃，不会把幻觉文字打进文档。

浮层里出现的准流式文字只是预览，不会自动上屏；真正写进去的是松手后的最终结果。

长听写

一次听写会话最长 120 秒。内部按单段不超过 30 秒切分，自动接续，不需要你说到一半停下来重新按。

适合口述周报、会议纪要、长段邮件。需要停顿思考时，继续按住即可；VAD 会把过长静音当作分段点。

Qwen3 精度档只适合短句（≤30 秒）。要做 1–2 分钟的长听写，请用 SenseVoice。

引擎与模型

两个引擎都在本机跑，不联网：

  • SenseVoice int8（默认）：233MB 下载 / 247MB 解包。25 条 TTS 金标语料 CER 0.093（中 0.028 / 英 0.125 / 混 0.159）。适合日常与长听写。
  • Qwen3-ASR int8（精度档）：879MB / 972MB。同语料 CER 0.040，但速度约慢 3 倍，峰值内存约 1.6GB，只建议短句。

设置 → 引擎可以直接点「下载」，完成后一键切换。也可以到模型页手动下载后放进模型目录。

另外三个小模型：标点 65MB、声纹 39MB、GTCRN 降噪 0.5MB、silero VAD 0.6MB。除 SenseVoice 外的模型都可以不用。

热词

热词是一张「听错的说法 → 正确写法」的表。例如把「深度求索」映射到 DeepSeek，把「通义」映射到 Qwen。

两种添加方式：

  • 设置 → 热词，手动增删改，⌘S 保存。
  • 上屏后你亲手改了某个词，应用会在约 15 秒内发现这次编辑，把「原词 → 新词」放进「学到的改法」，等你采纳或忽略。

热词页还会从历史里挑高频词作为建议，一键加入。热词表改动后立即生效，不需要重启。

热词只影响识别结果的替换，不会改变模型本身。映射宁少勿多，太短的词容易误伤正常文本。

上屏方式

两种策略，默认「粘贴」：

  • 粘贴：把文字放进剪贴板再合成 ⌘V / Ctrl+V，快，绝大多数 App 可用。
  • 逐字打字：逐个字符注入键盘事件，慢一些，但在终端、远程桌面、游戏输入框里更稳。

设置里可以给单个 App 覆盖策略，例如「终端一律逐字」。密码框会自动拒绝逐字上屏；提权窗口与部分特殊控件无法注入，这是系统限制。

如果提示「上屏结果未知」，文字已经保存在内存里，可以从菜单栏「复制上次结果」取回，再手动粘贴。

隐私模式

开启后同时做三件事：

  • 不写入历史记录；
  • 失败音频不落盘；
  • 浮层不显示识别文本，只显示状态。

适合会议、客服、医疗等场景。注意：隐私模式不改变上屏行为，文字仍然会进入你当前的输入框。

无论是否开启，识别链路的音频都不会离开本机。产品里只有三个网络出口：模型下载、可选的 LLM 润色、可选的诊断上传。详见隐私说明。

声纹与音源锁定

只识别我的声音：先录 8 秒声纹（本机 39MB 模型），之后只让匹配的声音进入识别。适合多人会议里只想记自己发言。

音源锁定（实验）：按段判断声源，插话多的场景可以更干净；但它按段丢弃，可能误伤你自己的话。旁边人声一直插话、而你想全记下来时，关掉它。

声纹不是安全认证，只是识别前的声源筛选。不要把它当作「防止他人冒用」的安全边界。

润色与选区改写

润色需要你填一个 OpenAI 兼容的 API 地址与 Key（默认 DeepSeek）。默认关闭；开启时应用会提示「这段文字会离开本机」。

  • 润色档位：轻度 / 标准 / 强，快捷键默认 ⌃⌥1–⌃⌥3。
  • 选区改写：选中文字后按 ⌘E，可选润色、正式、精炼、英文、总结五种。结果可就地替换。

发出去的是识别后的文字与你配置的服务端地址；音频仍然不出本机。不用时保持关闭即可。

局域网听写

实验功能，默认关闭。设置 → 音频 →「局域网听写接口（实验）」打开，改完需要重启应用。

它只做「音频 → 文字」：不上屏、不写历史、不动剪贴板。默认只监听 127.0.0.1:8765；要让手机访问，必须打开「允许局域网」并设置 token。

# 探活
curl -s -H "x-eryu-token: 你的token" http://127.0.0.1:8765/health

# 发一段 16kHz 单声道 WAV，取回文字
curl -s -H "x-eryu-token: 你的token" \
  --data-binary @speech.wav \
  http://127.0.0.1:8765/transcribe
不要把接口暴露到公网。允许局域网时一定设 token；用完关掉开关并重启。

排障

按了键没反应

看菜单栏 / 托盘图标有没有变化。没有变化说明热键没接住：检查设置 → 通用里是否有「冲突」红字，以及辅助功能、输入监控两项权限。刚授权完，用「退出并重新打开」再试。

浮层出来了但没字

看浮层右侧秒数是否在涨：不涨是麦克风没录到（查设备、静音键、输入音量）；涨了但一直「在听…」通常是你还没说完整句，VAD 没封口。

提示「声音太小了」

峰值低于 2% 一律不上屏，这是防幻觉策略。靠近麦克风，或把系统输入音量拉高。

提示「太短了」

默认最短 400ms。双击热键可以取回上一次结果，不用重说。

文字没进输入框

提权窗口、密码框、部分自绘控件无法注入。切「逐字打字」再试，或从菜单复制后手动粘贴。

权限明明给了还是不行

大概率是同一份 app 有多个副本，各自独立授权。只保留一个，移动后再授权。也可以看菜单栏「权限状态…」或 /tmp/eryu-perm.json。

数据与卸载

数据都在本机，不上传：

  • macOS：~/.eryu/（config.toml、models/、history.json、stats.json）。
  • Windows：%APPDATA%\Eryu\；exe 旁放 portable.txt 可改为便携模式。
  • 历史最多保留 200 条，可在设置里清空；统计含 p50 / p95 延迟。

卸载 macOS：退出应用，把 app 移到废纸篓；需要彻底清除时再删 ~/.eryu。

卸载 Windows：双击 uninstall-win.bat，或运行 uninstall-win.ps1 -PurgeData 连配置、模型、历史一起删。

命令行自测

macOS 版二进制在 Eryu.app/Contents/MacOS/Eryu，这些命令不需要辅助功能权限：

--diagnose        引擎 / 模型 / 设备 / 历史 / 权限状态
--mic-test 3      真实麦克风 → VAD → 识别，打印结果
--self-test       固定文字 → 事件流端到端
--print-last      取回崩溃前没上屏的那条
--dump-config     当前生效的 config.toml

遇到问题，优先用设置 → 诊断页的「复制状态」，它比截图更有用。
