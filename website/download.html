Install · macOS

装好，大约三分钟。

你需要：Apple Silicon Mac、macOS 13 或更新。轻量包约占 300MB；完整离线包约 1.3GB。

解压，拖进「应用程序」

双击 zip 得到 Eryu.app，把它拖到「应用程序」文件夹。不要直接在压缩包里运行。

第一次打开被系统拦下

提示「无法验证开发者」时，打开「系统设置 → 隐私与安全性」，在页面下方点「仍要打开」，再输入一次密码确认。

准备模型

轻量包：首次启动会问是否下载语音模型（SenseVoice 约 247MB、标点 65MB、降噪约 1MB），使用默认镜像，几分钟内完成。完整离线包：双击包内的 install-models.command，它会把模型复制到 ~/.eryu/models 并打开应用。

授予三项权限

麦克风（收音）、辅助功能（粘贴上屏、单键热键）、输入监控（键盘监听与合成 ⌘V）。少一项都能识别，但可能无法自动上屏。

按住右 Option 说一句

在任意输入框里按住右 Option，说一句话，松开。文字应落在光标处；没反应就去「设置 → 诊断」看权限状态。

如果「明明给了权限还是不行」：辅助功能与输入监控是按 app 文件路径 记的。把 app 移到「应用程序」之后再授权；同一份 app 不要留多个副本。
Install · Windows

解压，跑一次安装脚本。

你需要：Windows 10 或 11、64 位。轻量包约 500MB；完整离线包约 1.3GB。

完整解压

把 zip 解压到任意位置，不要直接在压缩包里双击 exe。标准包能看到 Eryu.exe、models\ 与 install-win.bat；完整离线包还多一个 models-extra\ 与 install-full.bat。

双击 install-win.bat

标准包双击 install-win.bat；完整离线包双击 install-full.bat，它会一并装好全部模型。两者都会创建开始菜单快捷方式，不需要管理员权限。若 SmartScreen 拦截，点「更多信息 → 仍要运行」。

从开始菜单启动

搜索「Eryu」启动（字在的内部代号），右下角出现托盘图标。第一次会走五步引导：模型就绪 → 麦克风 → 快捷键 → 上屏方式 → 试说一句。

设置快捷键与上屏方式

默认右 Alt。托盘图标右键 →「设置」，可以改热键、选粘贴或逐字上屏、按 App 单独指定策略。

在记事本里试一句

按住右 Alt 说话，松开。文字应出现在光标处；也可以在设置 →「音频」里点「测试 3 秒」看电平条。

关于名字：当前 Windows 安装包的可执行文件与开始菜单项仍叫 Eryu（项目内部代号），应用内设置页已经显示「字在」。命名会在下一个版本统一，不影响功能。
便携模式：在 Eryu.exe 旁边放一个空的 portable.txt，数据（配置、模型、历史）就写在 exe 旁边，不碰 %APPDATA%。

Verify

校验你的下载。

如果网络环境不可信，下载后先核对 SHA-256，再打开安装包。

# macOS
shasum -a 256 ~/Downloads/zzai-0.8.1-mac-arm64.zip
# 0e4bc9fd1ef8e2ae1fb3b4836c4acbc614cd8cdf505edd2fa8a1f20b942a1f43

# Windows（PowerShell / CMD）
certutil -hashfile zzai-0.8.1-win64.zip SHA256
# fed58b67908cc3a7b78be54dfb51cf244c3a278d0e2412c6a9e25819bcd21a44

同一份轻量安装包也会发布在 GitHub Releases。两处的文件内容一致，只是站点上的文件名统一成了 zzai 前缀。完整离线包的 SHA-256 显示在各自下载卡上，可直接复制。

源码、构建脚本与设计文档在 github.com/flyeasy/zzai，采用 Apache-2.0 许可。想自己编译，见仓库 README 的「从源码构建」。
