应用内下载

推荐路径。两个引擎在「设置 → 引擎」；标点、降噪、VAD、声纹在「设置 → 音频」或对应功能第一次开启时按需下载。

  • 下载带断点续传：中断后保留 .part，再点会接着下。
  • 镜像不可达时，可以在设置里清空「模型镜像」，应用会回退到 GitHub Releases。
  • 下载完成会自动解包到模型目录，不需要手动解压。

手动安装

把文件放进模型目录，重启应用即可被识别。压缩包要解到模型目录下，保持包里那层同名文件夹。

macOS
~/.eryu/models/
Windows
%APPDATA%\Eryu\models\（便携模式为 EryuData\models\）
# macOS 示例：把 SenseVoice 解到模型目录
mkdir -p ~/.eryu/models
tar xjf sherpa-onnx-sense-voice-zh-en-ja-ko-yue-int8-2025-09-09.tar.bz2 -C ~/.eryu/models

# 校验解包结果
ls ~/.eryu/models/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-int8-2025-09-09/model.int8.onnx

许可与体积说明

模型版权与许可归各自上游；字在只是调用方，不重新分发模型权重到源码仓库。安装包内含或下载的模型见上表。

  • 体积为十进制 MB 的近似值，解包后会略大（例如 SenseVoice 233 → 247 MB）。
  • 常驻内存：只装 SenseVoice 时约 550–570 MB；切到 Qwen3 峰值约 1.6 GB。
  • 所有推理都是 CPU（ONNX Runtime），不依赖 GPU、NPU 或厂商加速框架。
不确定该装哪个？只装 SenseVoice + 标点就够日常用；需要极致短句精度再下 Qwen3。
