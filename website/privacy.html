隐私说明

一句话：识别链路的音频只在本机处理。下面把「什么会离开这台电脑」逐条写清楚。

适用 v0.8.2·更新于 2026-11-22

音频不出本机

从麦克风采集、降噪、VAD 分段、声纹比对到语音识别，全部在你的电脑上完成。字在不保存原始录音，不上传音频，也不把音频写进日志。历史上只保存识别出来的文字。

要做到这一点，第一次使用需要下载模型（约 235MB 起）。这是下载，不是上传。

三个网络出口

应用里所有会联网的代码路径只有这三处：

1. 模型下载

默认从本站镜像 officeace.harmonyos.fun/eryu-models 拉取，镜像不可达时回退到 GitHub Releases。请求里只有文件名，不包含你的音频、文字或设备标识。

2. LLM 润色（默认关闭）

只有你主动开启并配置了 OpenAI 兼容的地址与 Key 才会发生。发送内容是你这次识别出来的文字和必要的指令，接收方是你自己填的那个服务端。字在不经手、不中转、不记录。

3. 诊断上传（默认关闭）

只有你在设置里点「上传诊断」才会发生。内容包括版本、系统版本、模型清单、最近的错误码与延迟统计；诊断包会脱敏，不包含识别正文、音频、剪贴板内容或历史记录。

不存在的东西

  • 没有账号系统，不需要注册或登录。
  • 没有遥测、埋点、崩溃自动上报或使用统计。
  • 没有广告 SDK、第三方分析 SDK。
  • 官网不使用 Cookie、不做访问画像；字体与图标随站点一起提供，不请求第三方 CDN。

本机保存了什么

配置
config.toml：热键、引擎、开关、镜像地址等。
模型
下载的 ONNX 文件，位于模型目录。
历史
最多 200 条识别结果与延迟，可在设置里清空。
统计
条数与 p50 / p95 延迟，不含文本。
声纹
只有你启用「只识别我的声音」时才生成，保存在本机。

macOS 位于 ~/.eryu/，Windows 位于 %APPDATA%\Eryu\。卸载应用不会自动删除这些文件，需要你手动清理。

系统权限为什么需要

  • 麦克风：收音，这是产品本身。
  • 辅助功能：把文字送进当前输入框、监听热键。
  • 输入监控：键盘事件与合成粘贴在部分应用里需要它。

三项都只服务于「听写并上屏」，不用于采集其他信息。

第三方组件

推理用 sherpa-onnx（ONNX Runtime），模型来自 k2-fsa 的上游发布。各组件的版权与许可见仓库里的 THIRD_PARTY.md ↗。应用本身以 Apache-2.0 开源。

你可以自己验证

源码全部公开：github.com/flyeasy/zzai ↗。网络请求的位置在 core/src/models.rs（模型下载）、润色客户端与诊断上传处，搜索 http 即可逐一核对。

变更与联系

这份说明随版本更新；有实质变化会在更新日志里注明。问题、疑问或安全报告请开 GitHub Issue ↗。

这是产品说明，不是法律意见。若你所在地区对语音数据处理有额外要求，请以当地法规为准。
